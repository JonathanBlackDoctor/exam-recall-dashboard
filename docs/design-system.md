# 화면 디자인 기준

2026-10-10 승인된 점수 안내 두 장의 네이비·블루 스타일을 로그인, 히트맵, 기여 요약, 과목 선택, 점수 안내, 모바일 화면에 공통 적용합니다.

## 색과 타이포그래피

| 역할 | 값 | 사용 |
|---|---|---|
| 네이비 | `#142238` | 제목·본문·숫자 |
| 코발트 블루 | `#3165e8` | 핵심 점수·버튼·선택·초점 |
| 블루 배경 | `#edf3ff` | 요약·안내 카드·활성 항목 |
| 페이지 배경 | `#f8f9fc` | 전체 화면 |
| 흰색 | `#ffffff` | 주요 패널 |
| 테두리 | `#dfe6f2` | 표·입력·구분선 |
| 보조 텍스트 | `#62718a` | 설명·메타 정보 |

시스템에 설치된 한국어 산세리프 글꼴을 사용합니다. 큰 제목과 핵심 점수, 짧은 설명, 얇은 구분선으로 읽는 순서를 만듭니다. 숫자는 고정 폭으로 정렬합니다. 아이콘은 저장소의 SVG 컴포넌트이며 외부 요청을 만들지 않습니다.

## 히트맵

- 척도별 고정 기준값과 `value / (value + pivot)`을 사용합니다. 과목·검색 선택에 따라 색을 다시 정규화하지 않습니다.
- 낮은 값은 `#ecf3ff`, 높은 값은 `#1e40af` 방향으로 이어집니다. 값에 따른 글자색을 선택하고 대비를 테스트합니다.
- 응시·무기여 0은 중립색, 미응시는 회색 사선과 `—`를 함께 사용합니다. 색만으로 상태를 전달하지 않습니다.
- 출석번호·이름 열과 과목·회차 헤더를 고정합니다. 상세에서 돌아올 때 표의 위치와 누른 칸의 초점을 복원합니다.

## 안내와 모바일

점수 안내는 배점·계산과 용어·판정 두 페이지입니다. 상단 페이지 선택과 하단 이동 버튼은 유지하고 본문만 스크롤합니다. 과목 선택은 적용 전 임시 선택을 사용하므로 닫으면 변경이 취소됩니다.

좁은 화면에서는 로그인과 상세 선택·안내 카드를 세로로 배치합니다. 히트맵은 패널 안에서만 가로로 스크롤합니다. 모달은 화면 안에 들어오며 Esc, 닫기, 바깥 클릭으로 종료하고 여는 버튼으로 초점을 돌립니다. 키보드 초점을 표시하고 움직임 감소 설정을 따릅니다.

데이터·계산·암호화는 디자인과 분리합니다. 실명 평문·비밀번호·실제 데이터 화면 캡처는 저장소에 추가하지 않습니다.
